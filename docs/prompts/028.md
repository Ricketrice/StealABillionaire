## Phase 1 — Worker Parade (D7)
- Mystery workers spawn at the spawn end of the red lane and walk slowly toward the plaza, then despawn. Max ~8 on the lane at once.
- They look like fun mystery figures (same look for all: e.g. silhouette in a gift-wrap/question-mark outfit with a bounce), not grey blobs. Real worker hidden until caught.
- Walk up → prompt → pay → rarity rolled server-side → reveal → worker is carried (existing carry system). First to catch wins; others see it vanish with a "Too slow!" puff.
- Pool + odds = existing Zone 1 pool and odds. Do not change existing odds, IDs, rarities or income.
- **First catch is free** for new players (tutorial step: Guide points at the lane).
- **Golden Parade** every ~15 min: 60-second gold-themed parade, countdown shown on the HUD and a sign over the lane, better odds for everyone, odds shown in the prompt.
- Server-wide message when anyone catches Legendary or Secret.
- Server-authoritative: catch remote validates distance, cash, cooldown and that the worker is still free (race-safe). Movement is cheap: server owns path progress, clients render and animate; no Humanoid pathfinding.
- Feature flag `ParadeEnabled`. Flag OFF = game behaves exactly as before.
- All new numbers (catch price, spawn interval, walk speed, Golden interval/length/odds boost) in one `ParadeConfig` module with sensible defaults. These are NEW numbers, so list them in the final report for my approval.

## Phase 2 — Juice + AI/code-driven animation (D8, D12)
Everything client-side, one master per effect, auto-cleanup, "Low effects" setting.
- **Reveal** for all 5 rarities, scaled: spin-up, rarity-coloured burst, sound sting, camera shake for Epic+, name + rarity banner. Legendary/Secret get a longer moment.
- **Carry:** worker wriggles over your head; Legendary+ leave a gold trail.
- **Place:** small celebration jump + coin burst.
- **Cash:** floating "+$X" over workers, counter rolls up.
- **Steal:** alarm light + sound on the victim's base, worker looks shocked, "SAFE!" burst when the thief gets home.
- **Idle on pads:** bounce and look around; Rare+ get one personality move each; Epic+ a soft aura (only when near the camera).
- Code-driven only (tweens, CFrame offsets, Motor6D transforms). No uploaded animations this milestone. Sounds from Roblox's licensed audio library only.

## Phase 3 — One-goal HUD + Collection book
- HUD always shows ONE next goal with a progress bar (e.g. "Catch your first worker", "Fill 6 pads", "Unlock Zone 6"). Big, icon-first, readable on phones.
- Collection book: one page per zone, caught workers in colour, missing ones as silhouettes with rarity. Derive from existing save data if possible. If a new saved field is needed, add it as optional with a default (schema stays 3). If that's not possible, ask me first.
