# 035art — Creature art pass (all 27, Aquaris V5 method)
Follow CLAUDE.md. Branch `art-aquaris` (or `art-<zone>` per batch) from `milestone-035`. Weak laptop: Blender + previews only until a batch is approved; Studio only for the import step.

## Why
The approved look is **Aquaris V5**: real modelled shapes, strong silhouette, clear palette, FX that frame the creature. Every creature gets that quality, not just the bosses. Audience ~80% kids on phones: cute or cool, never scary.

## Fixed rules (all batches)
- **Humanoids keep the noob body** (owner rule: yellow head, classic part-built smile or stern face, block torso/arms/legs). Their gear becomes Blender meshes at V5 quality: helmets, armour, robes, hats, capes, weapons, props.
- **Non-humanoids get a full Blender body** like Aquaris.
- Separate MeshParts per moving piece, pivots at real joints, Motor6D. Keep Humanoid + hidden R15 root + R15 names so wander, carry, pad, income, Index need no code changes.
- Colours via part Color/Material (no textures yet). Each mesh under Roblox's 20k-triangle import limit.
- **Triangle targets per creature:** Common ≤2k, Rare ≤3k, Epic ≤5k, Legendary ≤8k, Secret ≤12k. Part budgets unchanged (C30 / R45 / E80 / L150 / S250, FX parts included).
- Scale caps unchanged: carried 1.3x, pad 1.6x, Index/reveal full size.
- **FX tiers:** world (full, within ~80 studs), captured (carry/pad, subtle), UI cards (static glow parts only, particles don't render in ViewportFrames). Rarity sets FX size: Common none or tiny, Rare small sparkle, Epic aura, Legendary/Secret big aura.
- **Animation in code** (Motor6D on the client, one shared RunService loop, distance-gated, paused off-screen). No uploaded Animation assets. Write each creature's set as data:
  - Humanoids share ONE rig and ONE set: idle, walk, carried, pad idle, reveal pose, plus one **signature** move per creature (below).
  - Non-humanoids share a set per body type: swimmer (fish, seahorse), small walker (snail, newt), bird (owl, phoenix), big walker (golem, dragon).
- Don't change: IDs, names, rarities, odds, income, spawns, save schema, teammate zones.

## Batches (one pass each, then STOP for owner approval)
Each batch delivers ONE preview sheet in `~/Pictures/035_preview/<batch>/`: lineup of the whole batch next to a 5-stud noob, then per creature front / three-quarter / FX on / 128px icon + silhouette; a 3 s idle + signature preview (GIF or MP4); a report (triangles, MeshParts, parts, joints). Files for Import 3D go to `~/Documents/035/<batch>/`. After approval: import, wire into CreatureBuilder, run creature035 solo once (hangs → pending), commit, ask owner to File→Save.
